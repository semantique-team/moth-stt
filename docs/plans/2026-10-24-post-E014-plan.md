## Principles

- One variable per run; every run gets an `EXPERIMENTS.md` entry and a `runs/E-0NN/` directory.
- T is never trained on, and no sentence from T is reused in any script (the importer enforces it).
- New data needs a **defensible license**: CC0/BY only for training material; no NC/ND.
- No code merges into `main` while a training run is active (a resume must use the same code).
- The agent can prepare data, scripts and configs, and run evaluations; **recordings, sentence
  review and licensing decisions are the author's**.

## Phase 1 — E-016: gold fine-tune on S1 (agent, ~4 h unattended) — **done 2026-10-29**

Result: +20 ETA on T but **dominated by adaptation to S1** (control_it 34.7 → 18.1); other sets
are ties; the mixed gate still fails on ETA. See the E-016 entry. **Phase 3 is now mandatory**, and
a free check comes first: score E-016 and E-014 on T-S2 as soon as S2 delivers.

- [ ] Config `runs/E-016/config.yaml`: init **E-014 best**, 2 epochs, same continuation LRs as
      E-012/E-014 (head 3e-4 / encoder 5e-5), mixture **natural 438 h + gold R-S1 (≈50 min)
      oversampled to ≥20% of the batches** (the plan's H3a share; exact weight in the config
      comment), spliced set kept as in E-014 so the only change is the gold data.
- [ ] Smoke 50 steps, then the full run with `caffeinate -i`; checkpoint every 10 min.
- [ ] Eval with `runs/E-016/eval.sh` (greedy + beam+LM on FLEURS-IT/EN, CV test, T, noise).
- [ ] **Acceptance**: T ETA **≥ +5 points** over 20.60 with the WER paired CI not worse than 0;
      no significant loss on FLEURS-IT/EN beyond 1 point. Term-level readout on the 18 terms.
- [ ] Write the E-014/E-016 comparison in `EXPERIMENTS.md`.

**Caveat to state in the paper:** R-S1 and T are both S1 — same speaker, room and script style.
A gain here is real for the product but **optimistic** as a generalization claim. Phase 3 fixes it.

## Phase 2 — E-015: distillation pilot (needs a data decision)

- [ ] **Go/no-go**: if the pilot's ETA gain is < 2 points, stop; do not scale to 100 h.

## Phase 3 — cross-speaker gold (author + agent, the paper's validity fix)

- [ ] T S2 and S3 (200 takes each, ~1.5 h each) — the external-speaker guide already covers

## Explicitly out of scope until the gate is decided

Streaming, WebGPU, punctuation, word-level splicing (H3c word variant), capacity escalation
(conv head, 25 Hz), Whisper-base. Each would need an entry in `EXPERIMENTS.md` and a decision.
