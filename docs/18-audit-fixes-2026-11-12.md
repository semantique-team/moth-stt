## Code Scope

| Area | Worktree change / boundary |
|---|---|
| Audio deletion | `build_mel --delete-audio` verifies every current candidate, requires complete current-build coverage, fails on build/verification errors and bounds paths to the audio root. Limited builds retain excluded audio. Keep evaluation PCM regardless. |
| Text | Whitespace becomes separators rather than dropping tabs/newlines and joining words. Historical reproduction uses the pinned old normalizer. |
| Training | Shared split/source/role checks reject held-out T/A, FLEURS and S3; configured dev overlap checks cover IDs, splice/source IDs and comparable audio paths. Identical text with distinct audio is allowed. Not a full audio-hash, near-text or upstream audit. |
| Tokenizer / splicing | Training-only input validation; tokenizer pool rejects evaluation scripts/roles and normalizes text. No replacement tokenizer or new training run. |
| Browser | Referenced required model assets must declare valid SHA256 hashes; mic capture is capped at 30 s, trims retained samples, stops automatically and cleans up. Hash consistency is not publisher authenticity. |
| Windows | Native path serialization and trusted baseline shell path quoting fixes, rejecting unsafe Windows shell characters and preserving quoted placeholders. The historical `resource` import blocker was already fixed before this branch; production Windows training is not certified. |
| Scorer | Rejects duplicate IDs, missing/non-string hypotheses, invalid/overlapping spans and empty speech references. Extra IDs still need review; validation is not annotation adjudication. |
| Gate cache / artifacts | Fingerprints bind caches to inputs, assets, decoder and code; mismatches fail. Fresh names/output paths preserve historical gate, term and parity reports. |
| Required evidence | Music/non-music checks and attributed exact same-logit decoder parity required; omitted noise/parity is incomplete, not pass. Decoder parity is not browser acoustic WER. |
| Target-only readout | Adds aligned annotated target-token ETA as a diagnostic alongside the historical all-span rare-bearing subset, without replacing its gate. Retained-count recomputation is reported separately below. |
| Macro bootstrap | Adds paired within-language resampling and equal-language macro WER. Old pooled CIs remain pooled; the new retained audit readout reports macro intervals without reclassifying the old evaluation as independent. |
| Corpus / staging | Pins pre-E-032 git inputs, historical normalizer/receipt and original corpus identity; stages verified E-028/0.8.0 source assets with the pinned E-031 LM, not a generic 0.7 export. |
