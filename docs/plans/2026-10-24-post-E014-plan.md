## Principles

- One variable per run; every run gets an `EXPERIMENTS.md` entry and a `runs/E-0NN/` directory.
- T is never trained on, and no sentence from T is reused in any script (the importer enforces it).
- New data needs a **defensible license**: CC0/BY only for training material; no NC/ND.
- No code merges into `main` while a training run is active (a resume must use the same code).
- The agent can prepare data, scripts and configs, and run evaluations; **recordings, sentence
  review and licensing decisions are the author's**.
