# Moth 0.8.1

Released **2026-11-12**. This is the final release in this repository.

## What it is

A very small Italian + English code-switching speech recognizer: a pretrained
Whisper-tiny encoder (MIT), two additional transformer blocks and a linear CTC
head over a shared IT+EN SentencePiece BPE. It runs in the browser through ONNX
Runtime Web/WASM and on CPU.

## Results

| Set | n | WER | ETA |
|---|---:|---:|---:|
| Mixed test T, all speakers | 600 | 24.08 | 55.23 |
| T-S3 (held out from training; repeatedly evaluated) | 200 | 24.96 | 51.27 |
| FLEURS-IT test (filtered) | 697 | 20.16 | — |
| FLEURS-EN test (filtered) | 525 | 49.81 | — |

Decoder: beam 12, top-k 10, LM weight 0.55, token bonus 2.7, E-031 LM. These
are INT8 ONNX reference results, not browser acoustic measurements. T is
scripted read speech from three known voices; S3 informed development and is
not a pristine unseen speaker. See the paper's validity section.

## Reproducibility

The repository retains the experiment ledger, per-utterance hypotheses, metrics,
comparison JSON and release records. Checkpoints, raw audio, mel shards and the
serialized tokenizer are not versioned; a clean clone can re-score the paper but
cannot retrain the model. See
[`docs/20-archive-handover.md`](../docs/20-archive-handover.md).
